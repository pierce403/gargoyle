# 🏰 Gargoyle - Open Source Residential Surveillance Systems

Build your own privacy-focused surveillance system with open source software and off-the-shelf components available on Amazon. All data stays local - never touches the cloud.

## Overview

Gargoyle provides comprehensive instructions for building three types of surveillance platforms:

- **🚁 Gargoyle Sentry** - Autonomous drone surveillance platform
- **🗼 Gargoyle WatchTower** - Solar-powered fixed surveillance platform  
- **🏰 Gargoyle Rookery** - Central server system for data processing and storage

## Key Features

✅ **Privacy by Design** - All data processing happens locally on your network  
✅ **Open Source** - All software is open source and freely available  
✅ **Cost Effective** - Professional surveillance capabilities at fraction of commercial costs  
✅ **DIY Approach** - Build exactly what you need with off-the-shelf components  
✅ **Amazon Parts** - All components available on Amazon with direct links  

## Getting Started

Visit the **[Gargoyle Documentation Website](index.html)** for complete build instructions, parts lists, and software setup guides.

### Quick Start

1. Choose your surveillance platform(s):
   - [Sentry Drone Build Guide](sentry.html) - $400-800, 6-8 hours
   - [WatchTower Platform Guide](watchtower.html) - $600-1200, 4-6 hours  
   - [Rookery Server Guide](rookery.html) - $800-2000, 3-5 hours

2. Order components from the provided Amazon links
3. Follow the step-by-step build instructions
4. Configure the open source software stack
5. Integrate all platforms for complete coverage

## Local Development

To run the documentation website locally:

```bash
# Clone the repository
git clone https://github.com/pierce403/gargoyle.git
cd gargoyle

# Start local web server
python3 -m http.server 8000

# Open browser to http://localhost:8000
```
