Gargoyle Sentry

Autonomous Drone Surveillance Platform

The Gargoyle Sentry is a customizable quadcopter-based surveillance drone designed for automated perimeter patrols, area monitoring, and rapid response reconnaissance. Built from readily available components, it provides professional-grade aerial surveillance capabilities at a fraction of commercial system costs.

Build Instructions

1

Assemble the Frame

Start by assembling the carbon fiber frame according to the manufacturer's instructions. Ensure all screws are properly tightened and the frame is rigid.

  • Attach the four arms to the central frame body
  • Install the top and bottom plates
  • Mount the landing gear if included
2

Install Motors and ESCs

Mount the brushless motors to the frame arms and connect them to the electronic speed controllers.

  • Secure each motor to the arm with the provided screws
  • Connect motor wires to ESCs (order determines rotation direction)
  • Mount ESCs to the frame arms, ensuring good airflow
3

Flight Controller Setup

Install and configure the Pixhawk flight controller for autonomous operation.

  • Mount the flight controller with vibration dampeners
  • Connect ESC signal wires to the appropriate outputs
  • Install GPS module on a mast above the frame
  • Connect telemetry radio and power distribution
4

Camera and FPV System

Install the camera gimbal and video transmission system for surveillance capabilities.

  • Mount the camera gimbal to the front of the frame
  • Connect camera to gimbal controller and video transmitter
  • Install video transmitter antenna clear of propellers
  • Configure camera settings for optimal video quality

Software Configuration

🔧 Flight Controller Firmware

The Sentry uses ArduPilot firmware for autonomous flight capabilities:

  1. Download and install Mission Planner
  2. Flash the latest ArduCopter firmware to your Pixhawk
  3. Complete the initial setup wizard for calibration
  4. Configure waypoint missions for automated patrols

🎮 Ground Control

Control and monitor your Sentry using open source ground station software:

  1. Install QGroundControl or Mission Planner on your laptop
  2. Configure telemetry radio connection
  3. Set up real-time flight data display
  4. Program automated surveillance patterns

📡 Video Reception

Receive and record live video feed from the Sentry:

  1. Connect FPV receiver to your computer via USB capture device
  2. Use OBS Studio or similar software for recording
  3. Configure video overlay with telemetry data
  4. Set up automatic recording triggers

⚠️ Safety & Legal Considerations

Important Safety Notes

  • FAA Registration Required: Register your drone with the FAA if it weighs over 0.55 lbs
  • No-Fly Zones: Check airspace restrictions before every flight
  • Line of Sight: Maintain visual contact with the drone during flight
  • Privacy Laws: Respect privacy laws and neighbor's property rights
  • Battery Safety: Never leave LiPo batteries unattended while charging
